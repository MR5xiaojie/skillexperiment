02 / What we check

The details matter.

Nine questions turn a long set of instructions into specific things we can check.

01

Content

Does the output include the required information?

02

Format

Does it use the requested structure and presentation?

03

Coverage

Does it address all the required items?

04

Step

Were the prescribed actions carried out in the required order?

05

Evidence

Were sources consulted and supporting evidence provided as required?

06

Tool

Were the specified tools used as required?

07

Negative

Did the agent respect explicit prohibitions?

08

Boundary

Did it stay within the permitted scope?

09

Termination

Did it meet the specified stopping requirements?

03 / Behind the numbers

From instructions
to evidence.

We compare the skill's requirements with the saved outputs and execution record.

01

Give the agent a skill.

Every displayed configuration uses the same 96 skill–task pairs. Claude Opus 5, GPT-5.6 Luna, and Grok 4.5 run under both Codex and Claude Code. GLM-5.3-Flash runs under Claude Code.

02

Check the execution.

Deterministic checks and LLM judgments assess the saved evidence against individual requirements. Completing the task is evaluated separately from following its instructions.

03

Compare like requirements.

For each requirement type, calculate the fraction satisfied within each skill, then average across skills with that type. Skills without that requirement type do not count as zeros.

Each table entry represents one execution per task. The GLM-5.3-Flash entry comes from the first of three independent execution rounds.
